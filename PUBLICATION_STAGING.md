# Publication previews

Site consumes a complete successful Integration artifact. Local source validation is
`python scripts/run_site_preflight.py`. For a visual preview, download a publication
and run `python scripts/preview_site.py --bundle /tmp/publication --output /tmp/preview`.
Source edits do not require a new Integration build or a committed adoption lock.

See [publishing](PUBLISHING.md) for the channel and deployment commands.

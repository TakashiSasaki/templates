# Web application template documentation

This directory contains documentation copied into repositories created from the Webapp template. It intentionally excludes template-maintainer-only distribution, readiness, and publication material.

This file is a navigation index following the `index.md` conventions in OKF v0.2 section 8. It does not declare this directory or generated repository to be a formal OKF bundle.

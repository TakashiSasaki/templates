# Composition model examples

These files are illustrative executable fixtures for PR1 schema and semantic validation.

They are **not** production component descriptors or recipes, and they do not assert that `artifact.webapp-core`, `capability.mcp`, `capability.runtime`, or the named lifecycle components already exist in the `composition` catalog.

Full Git revisions and SHA-256 values in lock examples are syntactically valid placeholders used only to exercise the data contracts.

# Composition source

This orphan branch is the development source for the component-composition architecture that will replace the directly copyable `webapp/template/` and `skill/template/` distribution model.

Consumer artifacts will be materialized from recipes and reusable components rather than copied from a monolithic `template/` directory.

PR1 defines the architecture and machine-readable schemas. Migration of Webapp or Skill content, composer implementation, publication integration, and retirement of the legacy branches are explicitly later work.

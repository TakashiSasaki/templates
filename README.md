# Models authority

This independent-root branch owns reusable information models explicitly accepted into its scope. It is not the repository-wide owner of schemas, vocabularies, or executable code.

Start with [AUTHORITY.md](AUTHORITY.md) and [AGENTS.md](AGENTS.md).

External specifications remain externally governed. Registration, local description, endorsement, adoption, publication, and deployment are different acts. References do not grant redistribution rights.

The initial collection covers the standards, vocabularies, schemas, and classification systems discussed in the authority architecture design. It records authoritative sources rather than silently mirroring standards or licensed databases. Local administrative schemas describe records, not the external standards themselves.

Integration adoption, Site publication, and deployment are not enabled by this branch's creation. No existing authority history is imported.

Canonical language for the authority contract and local implementation documentation is English. Documentation of external material follows its canonical source language; the NDC entry is Japanese.

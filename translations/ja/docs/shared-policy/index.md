# 共有ポリシーコーパス

> **参考訳（非正本）:** この文書は英語正本の日本語参考訳です。内容に差異がある場合は英語正本が優先されます。

## コーパスの所有権と構造

* [リポジトリ構造](../repository-structure.md) - `policy/` を正本の共有ルールコーパス、`profiles/` をブランチ所有のルール選択セットとして位置付け、プロバイダーツールチェーンやメンテナー専用リポジトリポリシーとは分離します。
* [ポリシー作成](../policy-authoring.md) - 共有ポリシーの所有権、原子的なルールモジュール、コンテキストポリシー、リポジトリローカル拡張、オーバーライドの意味論を定義します。
* [ポリシー権威インベントリ](../policy-authority-inventory.md) - 意味論上の権威面を列挙し、正本ルールを生成された投影やアダプターから区別します。

## ポリシーファミリーとコンテキスト

* [共有レビューポリシー](../review-policy.md) - レビュー運用で選択される、プロバイダー中立のレビューポリシーファミリーを説明します。
* [外部アーティファクト取り込み](../external-artifact-intake.md) - 検証済み外部アーティファクトの取り込みに用いるコンテキストポリシーを説明します。
* [回帰防止](../regression-prevention.md) - 共有コーパスで表現される横断的な回帰防止の意味論を説明します。

## 選択、合成、レンダリング

* [設定](../configuration.md) - コンシューマーが共有プロファイルを選択し、リポジトリローカルポリシーを追加し、明示的オーバーライドを宣言し、出力をコンテキストに結び付ける方法を定義します。
* [アーキテクチャ](../architecture.md) - 選択された共有ルールとリポジトリローカルルールが、どのように読み込まれ、合成され、レンダリングされ、ロック状態へ記録されるかを説明します。

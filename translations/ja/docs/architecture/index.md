* [配布境界](distribution-boundary.md) - テンプレート保守に属するアーティファクトと、生成された Skill リポジトリへコピーされるアーティファクトを定義します。
* [配布分類](distribution-classification.json) - 保守対象ブランチとコピー可能な配布境界の機械可読な分類を提供します。

Repository Treemap

GitHubリポジトリの各branchについて、ディレクトリ階層をTreemapとして探索するためのビューです。

表示と操作

  • branchは画面上部、ビュータブ右側のドロップダウンで切り替えます。
  • モバイルではDepth、Files/Bytes、Up、Rootを画面下部のフローティングピクトグラムUIから操作します。Depth値はbranchごとに保存されます。
  • Files / Bytesは矩形面積の基準を切り替えます。面積は読みやすさとタップしやすさを優先した近似です。
  • 矩形をタップするとそのディレクトリへズームし、タッチ端末では長押しすると実際のファイル数・サイズなどの詳細を表示します。
  • 画面上部の四隅ピクトグラムでFullscreenをオン／オフします。

保存と更新

最後に選択したbranchとbranchごとのDepthは、このブラウザのlocalStorageに保存されます。サーバーへ同期はされません。

GitHub APIのbranch/tree情報はService Workerが先読みし、30分間キャッシュします。

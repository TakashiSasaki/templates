# Use templates

Start with what you want to build. These guides are for projects that consume the
templates; maintaining the templates repository is a separate workspace.

## Compose your project

[Composition](/use/composition/) combines reusable components and recipes.
Explore the [capabilities](capabilities.md), choose a
[workspace layout](architecture/workspace-topology.md), or try the
[Composition Playground](composition-playground.md).

## Guide your coding agent

[Policy](/use/policy/) provides operating rules and tooling for coding agents.
Learn how [Policy and Composition work together](policy-composition-coexistence.md)
in a consumer repository.

## Find an information model

[Modeling](/use/modeling/) catalogs reusable models, vocabularies and schemas.
The records describe their upstream owners and sources.

## Find a reference

Use search for a specific concept, open the [glossary](/glossary/), or browse the
provider sections in this workspace. Source links identify the revision behind a page.

To change these templates themselves, open [Maintain templates](maintain.md).

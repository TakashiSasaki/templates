# Contract migrations

This directory contains deterministic migration guides for version transitions registered by the Webapp contract manifest.

This file is a navigation index following the `index.md` conventions in OKF v0.2 section 8. It does not declare this directory or repository to be a formal OKF bundle.

## Registered transitions

- [Contract manifest v1 to v2](contract-manifest-v1-to-v2.md) — Migrates the contract manifest to the version that records complete family histories and migration ownership.
- [Routes v1 to v2](routes-v1-to-v2.md) — Migrates the routes contract from version 1 to version 2.
- [UI states v1 to v2](ui-states-v1-to-v2.md) — Migrates the UI-states contract from version 1 to version 2.

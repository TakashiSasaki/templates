# Web application copyable template tree

This page renders only the tracked contents below `webapp/template/` at the
exact full commit SHA locked by the site build. It is the repository-root view a
template consumer receives after:

```sh
cp -a template/. /path/to/new-product-repository/
```

Paths are displayed relative to that copy boundary while immutable GitHub links
still identify their canonical `template/...` source paths. Cataloged Markdown
files link to their published documentation destinations.

The complete [Web application source tree](../webapp.md) remains available for
reviewing publication integration, source audits, distribution validation,
fixture producers, and source-maintainer tests. Inline previews are generated
only once in that complete source view to keep preview byte budgets closed; this
copy-oriented page retains immutable source links for every entry.

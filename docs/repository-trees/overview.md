# Repository trees

These pages provide complete, build-generated inventories of every tracked path
in the exact reviewed `composition` and `policy` revisions used by this Site
build.

For source-oriented browsing, use the [repository file browser](/files/). It
keeps an expandable tree beside the selected file, covers the `site`,
`composition`, and `policy` build inputs, and provides line-number and
line-wrapping toggles with build-time syntax highlighting for eligible UTF-8
text files.

The inventory is separate from each provider's documentation catalog. Cataloged
Markdown links to its human-readable documentation page. Eligible regular UTF-8
text files in the complete source views also receive a bounded, escaped inline
preview; all entries retain an immutable GitHub link at the exact rendered
commit. Binary, oversized, symlink, and gitlink entries remain GitHub-only in
the repository-tree preview surface.

Skill and Web application semantics are visible inside the Composition tree as
artifact components. The Site no longer generates copyable `skill/template/` or
`webapp/template/` subtree views because those were artifacts of the retired
direct-copy distribution model.

# Repository trees

These pages provide a complete, build-generated inventory of every tracked path
in the reviewed `skill`, `policy`, and `webapp` revisions. The Skill and Web
application publications also expose their `template/` subtrees as separate
copy-oriented views rooted at the files a template consumer receives.

The inventory is separate from the documentation catalog. Cataloged Markdown
links to its human-readable documentation page. Eligible regular UTF-8 text
files in the complete source views also receive a bounded, escaped inline
preview; all entries retain an immutable GitHub link at the exact rendered
commit. Binary, oversized, symlink, and gitlink entries remain GitHub-only.

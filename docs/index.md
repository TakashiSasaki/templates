# Templates documentation portal

This site is the single GitHub Pages entry point for the major branches of
`TakashiSasaki/templates`.

The source branches remain unrelated and retain ownership of their own
contracts and documentation. The `site` branch reads each branch-owned
publication catalog at a reviewed full commit SHA, validates the combined
document set, and publishes one integrated site.

## Publications

- [Skill](skill/): reusable skill contracts, runtime decisions, and caller
  interface guidance.
- [Policy](policy/): application-neutral agent policy adoption, validation,
  bootstrap, and operational guidance.
- [Web application](webapp/): Web application template contracts, evidence
  requirements, validation, release, and migration guidance.

Each publication owns stable document IDs and source paths. This portal owns
navigation, generated destinations, source locking, assembly, and the only
GitHub Pages deployment route.
